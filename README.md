# 23f1000932_MLOPS_WEEKLY_ASSIGNMENT — Week 2

## DVC Integration for the IRIS Pipeline

This branch (`week_2`) extends the Week 1 IRIS pipeline by adding **Data Version
Control (DVC)**, giving full version history for datasets and trained models, backed
by Google Cloud Storage.

## Objective

Integrate DVC into the IRIS pipeline so that:
1. Every version of the data and the model trained on it is tracked in Git via
   lightweight `.dvc` pointer files.
2. The actual data/model content is stored in a GCS remote, not in Git.
3. It's possible to switch between any previous version of data/model using
   `git checkout` + `dvc checkout`.

## Repository Contents (week_2 branch)

| File / Folder | Purpose |
|---|---|
| `train.py` | Standalone training script — reads `data/iris.csv`, trains a `DecisionTreeClassifier`, prints evaluation accuracy, and saves `model.joblib`. |
| `augment_data.py` | Simulates new incoming data by adding noisy duplicate rows to `data/iris.csv`, used to create a second data iteration. |
| `data/iris.csv.dvc` | DVC pointer file referencing the tracked version of the IRIS dataset. The actual CSV is stored in the GCS remote, not in Git. |
| `model.joblib.dvc` | DVC pointer file referencing the tracked version of the trained model. The actual model file is stored in the GCS remote. |
| `.dvc/config` | DVC configuration, including the GCS remote URL. |
| `.dvcignore` | Auto-generated by `dvc init`. |
| `.gitignore` | Updated by DVC to exclude the real `iris.csv` and `model.joblib` from Git tracking. |
| `README.md` | This file. |

## What is NOT included (by design)

- Raw `iris.csv` and `model.joblib` — these are DVC-tracked, not Git-tracked, and live
  in the GCS remote at `gs://23f1000932-mlops-week1/dvc-store/`.
- Video screencast — submitted separately per assignment instructions.

## Pipeline Summary

1. **DVC Init** — Initialized DVC in the repository (`dvc init`), committing `.dvc/`
   and `.dvcignore` to Git.
2. **GCS Remote** — Configured `gs://23f1000932-mlops-week1/dvc-store/` as the
   default DVC remote.
3. **Iteration 1** — Tracked the baseline IRIS dataset (150 rows) and the model
   trained on it with `dvc add` + `git commit`.
4. **Iteration 2** — Simulated new incoming data using `augment_data.py` (+30 rows,
   180 total), retrained the model, and tracked both with DVC as a new version.
5. **Version Switching** — Used `git checkout <commit> -- *.dvc` followed by
   `dvc checkout` to revert the workspace to Iteration 1's exact data and model, then
   returned to the latest version the same way — demonstrated in the screencast.

## Cloud Resources Used

- **Vertex AI Workbench** — environment for running DVC commands and training scripts.
- **Google Cloud Storage** — DVC remote storage for all tracked data/model versions.
- **Git + DVC** — version control layer; Git tracks code and pointer files, DVC
  tracks the actual data/model content.
